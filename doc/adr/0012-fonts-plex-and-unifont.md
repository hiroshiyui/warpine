# ADR-0012: Draw PM text with IBM Plex and text mode with GNU Unifont

- **Status:** Accepted
- **Date:** 2026-11-15
- **Sources:** commit def03f2 ("render all Presentation Manager text in IBM Plex"); developer guide (PM Typography); `build.rs`; `vendor/ibm-plex`

## Context

PM programs ask for fonts by OS/2 face names (System Proportional, Helv, Tms Rmn, Courier …), and IBM's own fonts cannot be shipped. Text mode needs a fixed 8×16 cell font that covers the codepages, including double-width DBCS characters.

## Decision

- **PM:** all PM text is drawn from the IBM Plex families (Sans, Serif, Mono, and Sans JP / KR / TC / SC for CJK), vendored under SIL OFL 1.1, embedded in the binary and rasterised with `ab_glyph`. OS/2 face names map to a Plex family; a character missing from a face falls back to the CJK faces, then to Unifont.
- **Text mode:** the VIO console keeps 8×16 bitmap glyphs from GNU Unifont (half-width and double-width tables generated by `build.rs`).

## Consequences

- Fonts are freely redistributable and look consistent on every host.
- Text metrics differ from IBM's fonts, so layouts measured against real OS/2 can differ slightly.
- The binary is larger because the fonts are embedded.
