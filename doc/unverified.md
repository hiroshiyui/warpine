# Unverified behaviour

Choices Warpine made where no public source settles what OS/2 does. Each is a
guess to check if a reference turns up. Open work is in [TODOs](TODOs.md). Newer
features keep this list in their ADR, under "Warpine's choices (unverified)".

- **Notebook looks**: the back-page corners and the binding opposite, the rounded / polygon tab cuts (5 pels), the spiral loops, and a notebook button's `hImage` as a square left of its text.

## Kernel and processes

- **Queue limits**: a queue holds at most 65,536 elements and 256 MB of copied data, and `DosWriteQueue` answers `ERROR_QUE_NO_MEMORY` past either (OS/2 bounds a queue by the shared memory its writers allocate; Warpine copies elements, so it sets limits of its own).
- **Exit lists**:
  - the 5 s grace even when a handler continues;
  - a routine that returns, calls `DosExit` or faults counting as `EXLST_EXIT`;
  - `EXLST_EXIT` outside processing → `ERROR_INVALID_FUNCTION`;
  - removing an unlisted routine or adding NULL → `ERROR_INVALID_DATA`;
  - re-adding a routine re-orders it;
  - at most 256 routines;
  - the exception chain emptied before each routine.
- **Shared memory**:
  - getting a block twice counting once;
  - `ERROR_INVALID_ADDRESS` for a non-block.
- **Semaphores**:
  - OS/2's limits;
  - the owner-died hand-over when a single thread ends;
  - a count of 0 in `DosQueryMutexSem`;
  - `DCE_POSTONE` / `DCE_AUTORESET`;
  - closing an owned mutex without waiters;
  - `ERROR_TIMEOUT` when the process ends;
  - pid / tid 0 for an unowned mutex;
  - `ERROR_INVALID_PARAMETER` for NULL outputs;
  - 0 written by a redundant `DosResetEventSem`;
  - names case-insensitive and unique across kinds;
  - `ERROR_SEM_NOT_FOUND` for the wrong kind;
  - `ERROR_INVALID_HANDLE` for deleting a non-member;
  - `ERROR_TOO_MANY_SEMAPHORES` before a duplicate;
  - muxwait flags with neither or both `DCMW_*`;
  - a closed member giving `ERROR_INVALID_HANDLE`;
  - wait-all returning the last record's user value.
- **The Landlock sandbox** (ADR-0111): the display and sound paths (tested with SDL's dummy drivers only); the whole runtime directory and `/dev` writable; the library directories executable; the program's directory readable.
- **Shared memory access** (ADR-0049 addenda): `ERROR_INVALID_PARAMETER` from `DosRead` / `DosWrite` for a buffer in a block not held; a get or give without `PAG_WRITE` is read-only to that process; asking again keeps the larger access; `DosQueryMem` reports an arena page the process does not hold as `PAG_FREE`.
- **No address randomisation in the guest** (ADR-0125): whether OS/2 itself randomised anything is not known.
- **The host and network databases, the resolver** (TCP32DLL 76–89): the host's `/etc/hosts`, `/etc/networks` and `/etc/resolv.conf` instead of `%ETC%`; hostents without aliases; `res_send`'s two rounds of five seconds; the `h_errno` each failure sets; no `_res`.
- **SOM dynamic dispatch** (ADR-0126): the apply-stub protocol and `somApplyInfo`; `TCKind`'s values (from C's numbering of the Reference's list); `tk_char` widened as signed; `somVaBuf_add`'s 1 / 0; telling Open Watcom's `va_list` from GCC's by what it leads to.
- **The keyboard's default echo** (on): the KBD reference names ASCII as the default input mode only; `KbdCharIn` taken not to depend on the mode.
- **The extended LIBPATHs** (`DosSetExtLIBPATH`): `%EndLIBPATH%` allowed in a BEGIN value and the reverse; `ERROR_INVALID_PARAMETER` for a value over 1024 bytes, `ERROR_NOT_ENOUGH_MEMORY` when the expansion makes it longer.
- **`PrfQueryProfile` / `PrfReset`**: lengths counting the NUL; `PMERR_BUFFER_TOO_SMALL` for a short buffer; `PMERR_INVALID_PARM` when `pszSysName` is not the system profile; `PL_ALTERED` posted with 0, 0 to every queue of the session; the user profile changed for the whole session (kept in its directory).
- **`WinSetCp(0)`** refused as an unknown codepage (`PMERR_RESOURCE_NOT_FOUND`): the PM Reference lists the codepages a queue takes and gives 0 no meaning.
- **The ANSI cursor position report** (`ESC[6n`): `ESC[row;colR` without zero padding and without a CR after it; served to `DosRead` of the console but not of redirected standard input; at most 256 bytes waiting.
- **The system-call filter** (ADR-0124): the deny list (checked on SDL's dummy drivers only); `clone3` answering `ENOSYS` relying on the C library's fallback to `clone`; the desktop server refusing `execve`; `personality`, `kcmp` and the NUMA calls left allowed.
- **Fuzzing** (ADR-0112): a minute per target in CI; the protocol target's shims for four constants and a helper.
- **Guests at ring 3** (ADR-0113): Warpine refusing, rather than performing, an API call's write through a guest pointer into the GDT, IDT, stubs or paging arena; one page per thread for the TSS and its ring-0 stack, at a ring-0 window after the FS window; the program-visible selectors kept, ring 0 getting new descriptors at the end of the GDT; a thread that cannot get its page tables not starting (no unpaged fallback); an exception's frame moved below the guest's ESP; the list of privileged instructions and the EFLAGS a context record may set (masked at both rings); `TC_EXCEPTION` for an unhandled privileged instruction; a paging arena of 191 blocks capping a process's 32-bit threads; the whole system area below the TIB and the whole 4 MB of the thunks protected; 16-bit programs at ring 3 paged, losing the low 64 KB (Warpine's BIOS data area copy).
- **Page states** (ADR-0114): free memory not present, but another thread may reach memory just freed through its TLB (only the freeing thread's is flushed); `DosQueryMem` on untracked memory answering from the page tables; `ERROR_ACCESS_DENIED` for committing committed pages, decommitting reserved ones or changing uncommitted ones; `PAG_GUARD` without `PAG_COMMIT` refused, and accepted by `DosSetMem` although `fSET` lacks it; an unhandled guard violation going on; `DosQueryMem` on an uncommitted page reporting the allocation's access; the TLB flushed by toggling CR3's write-through bit (KVM's reload observed, not documented); a page an object without the write flag shares with a writable one stays writable; a sparse stack growing wherever it is touched and without calling handlers, `XCPT_UNABLE_TO_GROW_STACK` once from its bottom two pages, stacks of fewer than four pages committed whole, the main thread's stack taken as the header's `STACKSIZE` below the entry ESP (committed whole without one), `PAG_EXECUTE` reported for executable objects only, sparse stacks only at ring 3.
- **The session's cgroup** (ADR-0116): 8 GB and 8192 tasks by default; waiting up to 500 ms for the move.
- **Threads per process** (ADR-0115): at most 736 a process, from Warpine's paging arena, not from OS/2; `ERROR_MAX_THRDS_REACHED` (164) when it is full, as at the session's `THREADS=` limit.
- **A program's own breakpoint** (`INT3`, `INT 3`): `XCPT_BREAKPOINT`, continuable, with the context's EIP and `ExceptionAddress` both just past the instruction (the processor's trap frame), so a handler that continues goes on after it; unhandled, `TC_EXCEPTION`. 16-bit code still ends as an unexpected breakpoint.
- **Exceptions and traps** (ADR-0110):
  - `DosUnwindException`: a record leaves the chain after its handler returns; handlers' results are ignored and nested unwinds not marked; `EH_EXIT_UNWIND` is never set; a target not on the chain is refused with `ERROR_INVALID_PARAMETER`, without unwinding; the report and context records are allocated per call;
  - `DosRaiseException` sets `ExceptionAddress` to its return address;
  - the low 64 KB are not present for 32-bit threads, and a page fault's `ExceptionInfo` is the access type and the address;
  - FS shows the TIB through a window page after the system area, with a 4 KB limit; an unpaged thread keeps a direct FS base;
  - frames of handlers left by `longjmp` are dropped at a later callback return above them;
  - the SDK's unwinder treats hardware codes and `XCPT_SIGNAL` as signal frames, and lets an exception pass a trapping instruction outside every call site.
- **Signals**:
  - the must-complete limit of 65535;
  - only thread 1's sections holding signals;
  - an interrupted `MCI_WAIT` playing on;
  - CMD.EXE ending its child when interrupted.
- **Threads**:
  - a thread's windows destroyed without `WM_DESTROY`;
  - thread 1 ending alone while others run;
  - the exit code when thread 1 returns;
  - `DosWaitThread(0)` with nothing left to wait for → `ERROR_INVALID_THREADID`;
  - an ended thread reported once;
  - `DosKillThread` on itself;
  - its queue destroyed with it;
  - thread ids not reused.
- **Critical sections, timers, modules**:
  - a thread ending inside a section ends the section;
  - held threads ending with the process;
  - `ERROR_INVALID_THREADID` never returned;
  - the 32 ms tick, an interval of 0 as one tick, 64 timers;
  - a one-shot handle invalid after posting;
  - a closed semaphore stopping its timer;
  - "shared" meaning `DC_SEM_SHARED` or named;
  - `DosSearchPath` skipping unresolved elements, matching files only and keeping the caller's spelling;
  - `DosQueryModuleName` for handle 0 and for built-in modules (`C:\OS2\DLL\NAME.DLL`).
- **Suballocation**:
  - the error codes;
  - first fit;
  - the 1024-pool and 65536-range limits;
  - `DOSSUB_SPARSE_OBJ` / `DOSSUB_SERIALIZE` changing nothing.
- **Profiles**:
  - a truncated `PrfQueryProfileData` returning TRUE, and a truncated string forced to end in NUL;
  - list sizes and counts;
  - `HINI_PROFILE` merging;
  - deleting what does not exist succeeding;
  - the last key removing its application;
  - NULL applications on write;
  - `PrfQueryProfileInt` overflow wrapping;
  - the 64 KB limit;
  - `PrfOpenProfile` creating files and reusing handles;
  - `PrfCloseProfile` of the system profiles failing;
  - the help calls' error codes and the `WinQueryHelpInstance` owner walk.

- **ANSI** (sources: OS/2 FAQ 5.12, REXX Tips & Tricks, `VioWrtTTY`):
  - `ESC[J` / `ESC[1J` ignored;
  - unknown sequences swallowed;
  - a lone `ESC` shown;
  - `ESC[?7h` as `ESC[=7h`;
  - `SGR 2` as normal intensity;
  - underline ignored;
  - fills in the ANSI attribute, and scrolled-in lines in 0x07;
  - wrap off overwriting the last column;
  - TAB to the next multiple of 8;
  - `ERROR_VIO_INVALID_PARMS` from `VioSetAnsi`;
  - one state per process;
  - LF returning to column 0;
  - display modes 0–3 as 40 / 80 × 25 text (mono and colour alike), set and cleared; 4–6 ignored.
- **Console handles**:
  - `ERROR_INVALID_HANDLE` writing to a closed standard handle;
  - `DosSetFilePtr` on the console (OS/2 may say `ERROR_SEEK_ON_DEVICE`).
- **End of piped input**:
  - waiting `KbdCharIn` / `KbdStringIn` calls end the process with 0;
  - a partial line returned first;
  - `IO_NOWAIT` reporting no character.
