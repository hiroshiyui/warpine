# Sample OS/2 Applications

These are small OS/2 programs compiled with Open Watcom v2, used to test and verify Warpine's API emulation.

## Prerequisites

```bash
./vendor/setup_watcom.sh    # Download Open Watcom compiler (once)
```

Snapshots built before 2026-08-11 have a broken OS/2 start-up (Open Watcom #1649): programs get an empty `argv` and no environment. `./vendor/setup_watcom.sh` warns about such a snapshot; `./vendor/setup_watcom.sh --refresh` replaces it, then rebuild the samples.

## Building

```bash
make -C samples              # Build every Open Watcom sample (rust_hello has its own steps)
make -C samples/<name>      # Build a single sample
```

The C samples also build with GCC or clang and the SDK (ADR-0101), into `samples/build/<cc>/<name>/` under the same file names; `WARPINE_SAMPLES=gcc` (or `clang`) makes the integration tests run those builds. Samples that need Open Watcom's own syntax (`#pragma aux`, `_asm`, 16-bit `_Pascal` declarations) carry an equivalent for the other compilers behind `#ifdef __WATCOMC__`.

```bash
samples/build_sdk.sh gcc                     # every sample; or clang; or name samples after it
CC_CMD=vendor/pinned/gcc OUT_TAG=gcc-pinned samples/build_sdk.sh gcc   # the pinned compiler (vendor/setup_compilers.sh)
```

## Rust Guest Binaries

`rust_hello` is built with the Warpine Rust guest toolchain (nightly Rust + `lx-link` linker):

```bash
# Install once:
rustup toolchain install nightly-2026-11-15 --component rust-src  # the dated nightly the guest crates pin
cargo build --bin lx_link && cp target/debug/lx_link ~/.cargo/bin/lx-link

# Build:
cd samples/rust_hello
cargo build \
  -Z build-std=core,alloc \
  -Z build-std-features=compiler-builtins-mem \
  -Z json-target-spec \
  --target ../../targets/i686-warpine-os2.json
```
